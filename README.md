# iad-machine-learning

В рамках курса Основы машинного обучения выполнены работы по следующим темам:
- kNN, линейная регрессия (файл `linear-regression.ipynb`)
- Градиентный спуск, линейная регрессия (файл `gradient-descent.ipynb`)
- Классификация текстов (файл `text-classification.ipynb`)
